# Master's Thesis Experiments

This repository contains experiments conducted as part of my master's thesis.
The experiments explore applications of the **pseudo-normal form** in the planar, restricted, circular three body problem (PCR3BP).

The implementation of the algorithm for computing the pseudo-normal form is available in [normal-forms repository](https://github.com/5arcoramphu5/normal-forms).

Calculations are located in the `experiments/` directory and include:
* verification of the correctness of the algorithm implementation,
* computation of a periodic orbit using numerical integration and the normal form,
* computation of periodic orbits of arbitrary period using numerical integration and the normal form,
* generation of plots used in the thesis.
